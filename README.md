# 🛒 E-commerce Review Rating Prediction

> **Predicting e-commerce product ratings from customer review text using NLP and Machine Learning**

This project develops an end-to-end **NLP and Machine Learning pipeline** to predict the rating of an e-commerce review based on its textual content.

The project is divided into two main stages:

1. **Sentiment Classification** — classify reviews as positive or negative using TF-IDF features.
2. **Rating Prediction** — use the sentiment probabilities generated by the classification models as features to predict the original review rating from **1 to 5 stars**.

The project uses the `Amazon_Reviews.csv` dataset and implements the main ML models from scratch for the sentiment classification stage.

---

## 📌 Project Overview

In e-commerce platforms, customers provide both:

* a **written review**
* a **numerical rating**

However, the sentiment expressed in the review text may not always perfectly match the given rating.

For example:

> "The product works perfectly and I absolutely love it."

would intuitively correspond to a high rating.

This project investigates whether information extracted from review text — particularly **sentiment probabilities** — can be used to predict the numerical rating.

### Main objectives

* Clean and preprocess raw review text.
* Extract textual features using **TF-IDF**.
* Build sentiment classification models.
* Generate sentiment probabilities from the trained models.
* Use these probabilities as features for rating prediction.
* Compare different regression models.
* Evaluate the prediction errors by rating level.

## 🧠 Methodology

### 1. Data Preprocessing

The review text is cleaned before feature extraction.

The preprocessing pipeline includes:

* Convert text to lowercase
* Remove HTML tags
* Remove URLs
* Remove numbers
* Remove punctuation
* Remove special characters
* Tokenization
* Stopword removal
* Lemmatization

The project keeps negation words such as `no`, `not`, and `nor` instead of removing them as stopwords, which helps preserve important sentiment information.

A `Review Length` feature is also generated from the number of tokens in each review.

---

### 2. Sentiment Label Construction

For sentiment classification, reviews with a rating of **3 stars are excluded** because they represent a neutral/middle rating.

The remaining ratings are converted into binary sentiment labels:

| Original Rating | Sentiment    |
| --------------- | ------------ |
| 1–2             | Negative `0` |
| 4–5             | Positive `1` |
| 3               | Removed      |

This transformation is implemented before TF-IDF feature extraction.

---

### 3. TF-IDF Feature Extraction

The cleaned review text is transformed into numerical features using **TF-IDF (Term Frequency–Inverse Document Frequency)**.

Configuration:

```text
max_features = 5000
ngram_range  = (1, 2)
min_df       = 2
max_df       = 0.90
```

Using `(1, 2)` means that both **unigrams** and **bigrams** are considered.

For example:

```text
"good product"
```

can generate features such as:

```text
good
product
good product
```

The implementation uses `TfidfVectorizer` from scikit-learn.

## 🤖 Sentiment Classification

Two classification algorithms are used:

### Logistic Regression

A custom Logistic Regression implementation is used for binary sentiment classification.

The pipeline uses **5-fold Stratified Cross-Validation** to generate out-of-fold sentiment probabilities. This helps avoid directly using predictions from a model trained on the same samples when these probabilities are later used as features for rating prediction.

### Multinomial Naive Bayes

A custom Multinomial Naive Bayes implementation is also trained on the TF-IDF representation.

The sentiment pipeline produces:

```text
LR probability
LR class probability
NB probability
NB class probability
```

These probabilities are then passed to the rating prediction stage.

## ⭐ Rating Prediction

The sentiment probabilities are used as input features for predicting the original rating.

For example:

```text
Review
   │
   ▼
TF-IDF
   │
   ▼
Sentiment Model
   │
   ▼
P(Positive)
   │
   ▼
Rating Prediction Model
   │
   ▼
Predicted Rating
```

Two regression models are evaluated:

* **Linear Regression**
* **Support Vector Regression (SVR)**

The predicted rating is clipped to the valid range:

```text
1 ≤ predicted rating ≤ 5
```

The implementation evaluates different combinations of sentiment features and regression models.

## 📊 Evaluation Metrics

The rating prediction stage uses four metrics.

### MAE — Mean Absolute Error

Measures the average absolute difference between the actual and predicted ratings.

```text
MAE = mean(|y_true - y_pred|)
```

Lower is better.

### RMSE — Root Mean Squared Error

Penalizes larger prediction errors more strongly.

```text
RMSE = sqrt(mean((y_true - y_pred)²))
```

Lower is better.

### R² — Coefficient of Determination

Measures how much variance in the target variable is explained by the model.

Higher is better.

### Within-1-Star Accuracy

Measures the percentage of predictions whose error is no more than one star:

```text
|actual rating - predicted rating| ≤ 1
```

Higher is better.

## 🔎 Error Analysis

The project performs additional error analysis according to the actual rating level.

For each rating from **1 to 5**, the pipeline calculates:

* Number of samples
* Mean Absolute Error
* Mean predicted rating

This helps identify whether the model performs differently on low, medium, and high ratings.

The analysis is saved to:

```text
outputs/error_analysis_by_rating.csv
outputs/error_analysis_by_rating.png
```

The repository also stores residual and actual-vs-predicted visualizations for further model analysis.

## 💡 Key Takeaways

This project demonstrates an end-to-end NLP workflow in which **textual sentiment is transformed into numerical features and subsequently used for rating prediction**.

The main idea can be summarized as:

```text
Review Text
     ↓
TF-IDF
     ↓
Sentiment Probability
     ↓
Regression Model
     ↓
Predicted Rating
```

Rather than directly predicting a 1–5 rating from thousands of TF-IDF features, the project first extracts a more compact representation of the review's sentiment and then uses that information for the downstream regression task.
